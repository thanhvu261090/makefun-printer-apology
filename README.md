One funny line: an apology note from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it.

> Sorry about the pink spreadsheet. My cyan died in 2019 and nobody has checked on me since.

## Run it

```sh
python3 main.py
```

The program prints the line and writes it to `/output/entry.txt` (90 characters, one line — inside the competition's 120-character gate).

## Why this line

The printer is genuinely sorry, and it has its own gripe: its cyan ink died years ago and nobody ever checked on it, so every report comes out pink. A real printer complaint, with the punch at the end.
